KEY FEATURES
================================================================================

CHECKPOINT RESUMING:
  • Automatically detects latest checkpoint
  • Continues training from checkpoint if interrupted
  • No manual recovery needed
  • Loss-free interruption handling

COMPLETION TRACKING:
  • Automatically detects completed experiments
  • Skips training if SKIP_COMPLETED=True
  • Checks for model files (pytorch_model.bin, tokenizer.json)

METADATA SAVING:
  • Saves results as JSON after each experiment
  • Includes timestamp, hyperparameters, metrics
  • Useful for audit trail and debugging

CONFIG MANAGEMENT:
  • All constants in one place (Cell 3)
  • Easy to modify: MODEL, DATASET, HYPERPARAMETERS
  • Toggle features: RESUME_FROM_CHECKPOINT, SKIP_COMPLETED

================================================================================
USAGE INSTRUCTIONS
================================================================================

INITIAL SETUP:
  1. Open the notebook
  2. Edit Cell 3 constants:
     DATASET_DIR = "/path/to/your/dataset"
     OUTPUT_BASE = "/path/to/your/output"
  3. Adjust hyperparameters if needed

RUNNING TRAINING:
  1. Execute cells 0-9 in order
  2. After Cell 3, you'll see experiment status:
     [✓ COMPLETED] - Skip
     [⟳ CHECKPOINT] - Resume
     [○ NOT STARTED] - Train fresh
  3. Run Cell 8 - it will handle everything automatically

AFTER INTERRUPTION:
  1. Just re-run Cell 8
  2. It will automatically resume checkpoints
  3. No data loss, no manual recovery

DISABLE FEATURES:
  Set in Cell 3:
    RESUME_FROM_CHECKPOINT = False  (don't resume)
    SKIP_COMPLETED = False           (re-train all)

2. Resume Test:

   • Re-run Cell 8
   • Verify it detects checkpoint and resumes
   • Verify training continues from where it stopped

3. Skip Test:
   • Run training to completion
   • Set SKIP_COMPLETED = True
   • Re-run Cell 8
   • Verify completed experiments are skipped
   • Verify new experiments still train

4. Mixed Test:
